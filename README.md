# Ultra-Low-Power-IoT-Environmental-Monitor

Repository structure for an ultra-low-power IoT environmental monitoring project.

## Layout

- `docs/` for architecture, circuit, power, and datasheet documents
- `hardware/` for BOMs, pin maps, component lists, and enclosure assets
- `firmware/` for embedded source code and PlatformIO configuration
- `simulations/` for Proteus, Wokwi, and simulation results
- `images/` for prototype and demo media
- `results/` for logs, captures, and reports
- `presentation/` for slides and poster materials
